
# Description

Template for workflows.

# Workflow setup

## lib

* The `lib` directory contains general libraries that may be referenced by multiple workflows, for instance cromwell configs and python configs.


## scripts

* The `scripts` directory contains general scripts that may be referenced by multiple workflows, or commonly used.

## projects

* A project is usually a complete set of pipelines and scripts used for a specific project/publication.
